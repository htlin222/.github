# Getting help · 求助

| You want to… | Go to |
|---|---|
| Report something broken | the repo's **Issues → 🩸 Bug report** |
| Suggest a feature | the repo's **Issues → 📋 Feature request** |
| Ask how to use something | the repo's **Discussions** tab if enabled, otherwise an issue with the `question` label |
| Report a security problem | [SECURITY.md](SECURITY.md) — privately, please |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before asking, the README and `AGENTS.md` of each repo usually answer install and usage questions — and an AI coding agent pointed at the repo can often answer the rest.

發問前先看 README 與 AGENTS.md；把 AI 程式助理指向該 repo，常常也能直接回答。

**Not medical advice.** Nothing in these projects replaces clinical judgment or official guidelines.
本專案內容不構成醫療建議。
