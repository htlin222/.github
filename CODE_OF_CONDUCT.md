# Code of Conduct · 行為準則

These projects adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([繁體中文](https://www.contributor-covenant.org/zh-tw/version/2/1/code_of_conduct/)).

In short — treat people the way you would want to be treated on the ward:

- Be kind and assume good intent. Critique ideas, not people.
- Welcome newcomers; nobody was born knowing git or statistics.
- No harassment, discrimination or personal attacks, in any language.
- Respect privacy: never post anyone's personal or patient information.

簡單說：像在病房裡對待同事一樣對待彼此——友善、對事不對人、歡迎新手、不騷擾、不洩漏任何人或病人的隱私。

## Reporting · 回報

If something here made you feel unwelcome or unsafe, report it privately to the maintainer through GitHub (open a [private security advisory](https://github.com/htlin222/.github/security/advisories/new) and mark it as a conduct report) or contact the maintainer directly via the email on their GitHub profile. Reports are handled confidentially.
